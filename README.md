# Contact Manager

A beginner-friendly Contact Manager application built with Python.

## Features

* Add contacts
* Show all contacts
* Search contacts by name
* Edit contacts
* Delete contacts with confirmation
* Validate phone numbers
* Validate email addresses
* Prevent duplicate phone numbers
* Save contacts to a JSON file
* Load contacts automatically when the program starts
* Handle missing or invalid JSON files

## Technologies

* Python
* JSON

## How to Run

1. Make sure Python is installed.
2. Clone this repository.
3. Open the project folder in VS Code or a terminal.
4. Run:

```bash
python main.py
```
